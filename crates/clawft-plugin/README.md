# clawft-plugin

Plugin trait definitions for clawft.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-plugin = "0.8.4"
```

## Features

- `native` (default)
- `voice`
- `voice-stt`
- `voice-tts`
- `voice-vad`
- `voice-wake`
- `voice-wake-rustpotter`
