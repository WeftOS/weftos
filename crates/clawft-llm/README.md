# clawft-llm

LLM provider abstraction for clawft (OpenAI-compatible + native providers).

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-llm = "0.8.4"
```

## Features

- `native` (default)
- `browser`
