# clawft-cow-memory

Branchable, checkpointable memory over rvf-runtime::RvfStore (agenticow semantics, ported to Rust).

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-cow-memory = "0.8.4"
```
