# clawft-tools

Tool implementations for clawft (file, shell, memory).

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-tools = "0.8.4"
```

## Features

- `native-exec` (default)
- `native` (default)
- `subagent` (default)
- `browser`
- `browser-opfs`
- `canvas`
- `vector-memory`
- `delegate`
- `voice`
