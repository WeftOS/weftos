# clawft-channels

Channel plugin system for clawft.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-channels = "0.8.4"
```

## Features

- `native` (default)
- `email`
- `whatsapp`
- `signal`
- `matrix`
- `google-chat`
- `irc`
- `teams`
- `voice`
- `voice-real-audio`
- `real-audio-test`
- `voice-xai`
- `diarization-sherpa`
- `discord-voice`
