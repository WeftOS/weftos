# clawft-substrate

WeftOS substrate state tree + OntologyAdapter contract (ADR-017). M1.5 ships the kernel adapter; additional adapters (git, gh, fs, lsp, workspace, deployment) arrive in M1.6+.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-substrate = "0.8.4"
```
