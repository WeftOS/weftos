# clawft-rpc

RPC client and protocol types for communicating with the WeftOS kernel daemon.

`clawft-rpc` — RPC client and protocol types for the WeftOS kernel daemon.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-rpc = "0.8.4"
```
