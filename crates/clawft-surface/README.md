# clawft-surface

Surface description IR + TOML parser + binding expression evaluator + composer runtime (ADR-016 M1.5 subset).

`clawft-surface` — surface-description IR, TOML + Rust builder parsers, binding expression evaluator, and composer runtime that drives the shared canon primitives in `clawft_canon`.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-surface = "0.8.4"
```
