# clawft-canon

Primitive canon widgets + return-signal types (ADR-001 / ADR-006) shared by clawft-surface composer and clawft-gui-egui.

Primitive canon — the 21-item vocabulary every renderer speaks.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-canon = "0.8.4"
```
