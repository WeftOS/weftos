# clawft-service-llm

WeftOS LLM service — HTTP client to a locally-hosted llama.cpp (or any OpenAI-compatible) chat-completions endpoint, exposed to the daemon as the `llm.prompt` RPC.

WeftOS LLM service — HTTP client to an OpenAI-compatible chat completions endpoint (typically a local `llama-server`).

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-service-llm = "0.8.4"
```
