# weftos-worldmodel

LeWM latent world-model facade: re-exports core traits + default impls (single entrypoint for consumers). WEFT-522.

`weftos-worldmodel` — single user-facing entrypoint for the LeWM latent world model (WEFT-522).

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
weftos-worldmodel = "0.8.4"
```

- `candle`
