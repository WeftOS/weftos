# clawft-app

WeftOS app manifest parser, validator, and local app registry (ADR-015).

`clawft-app` — WeftOS app manifest parser + local app registry.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-app = "0.8.4"
```
