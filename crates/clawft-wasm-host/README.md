# clawft-wasm-host

Native wasmtime host runtime for clawft WASM plugins (sandbox, engine, audit, permissions).

Native wasmtime host for clawft WASM plugins (WEFT-398).

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-wasm-host = "0.8.4"
```
