# weftos

WeftOS: A portable AI kernel with process management, mesh networking, and cognitive substrate.

WeftOS: A portable AI kernel for any project.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
weftos = "0.8.4"
```

## Features

- `native` (default)
- `exochain`
- `cluster`
- `mesh`
- `ecc`
- `wasm-sandbox`
- `containers`
- `os-patterns`
- `full`
