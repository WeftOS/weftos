# clawft-plugin-treesitter

Code analysis via tree-sitter tool plugin for clawft.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-plugin-treesitter = "0.8.4"
```

## Features

- `rust`
- `typescript`
- `python`
- `javascript`
