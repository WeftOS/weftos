# weft-licence-wire

Wire types of the ADR-106 Seed licence proxy (checkout grant, signed envelope, mesh id), shared by the kernel (member side) and weft-licence (Seed side, armv7/aarch64).

Wire types of the ADR-106 Seed licence proxy: the checkout grant, the signed envelope, the mesh id and the shared error type.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
weft-licence-wire = "0.8.4"
```
