# clawft-service-terminal

WeftOS terminal service — daemon-side PTY allocation and shell hosting. Surfaces interactive shells over JSON-RPC for the egui Explorer terminal panel and any other surface that wants the same sessions (Cursor webview, future remote SSH).

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-service-terminal = "0.8.4"
```
