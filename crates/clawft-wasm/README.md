# clawft-wasm

WASM entrypoint for clawft (browser + wasip2).

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-wasm = "0.8.4"
```

## Features

- `project-kernel`
- `browser`
- `browser-opfs`
- `wasm-plugins`
- `alloc-talc`
- `alloc-lol`
- `alloc-tracing`
