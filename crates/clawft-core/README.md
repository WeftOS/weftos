# clawft-core

Core engine for clawft (agent loop, message bus, context management).

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-core = "0.8.4"
```

## Features

- `full` (default)
- `native` (default)
- `real-tokenizer`
- `browser`
- `vector-memory`
- `rvf`
- `signing`
- `embedding-router`
- `hybrid-rerank`
