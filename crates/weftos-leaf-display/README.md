# weftos-leaf-display

LeafSurface display-bus primitive + layer compositor for WeftOS leaf devices (no_std).

`weftos-leaf-display` — the `LeafSurface` display-bus primitive plus a generic layer compositor for WeftOS leaf devices.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.1.0.

## Use

```toml
[dependencies]
weftos-leaf-display = "0.1.0"
```
