# weftos-exo-dag

K6 substrate DAG: in-memory DagStore + MMR + Sparse Merkle Tree (ADR-043 / WEFT-619). No postgres.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
weftos-exo-dag = "0.8.4"
```
