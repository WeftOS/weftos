# clawft-kernel

WeftOS kernel: boot sequence, process table, service registry, and health subsystem.

WeftOS kernel layer for clawft.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-kernel = "0.8.4"
```
