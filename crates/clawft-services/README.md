# clawft-services

Services for clawft (cron, heartbeat, MCP).

Services for the clawft framework.

Part of [WeftOS](https://github.com/WeftOS/weftos), version 0.8.4.

## Use

```toml
[dependencies]
clawft-services = "0.8.4"
```

## Features

- `delegate`
- `rvf`
- `test-utils`
- `clawhub`
- `api`
