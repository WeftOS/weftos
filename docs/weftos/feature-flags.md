# Feature Flag Reference

This page used to catalog the Cargo feature flags of 22 workspace crates. The
workspace now has far more members, so the catalog was removed to avoid
drifting out of date. Use these references instead:

- [FEATURE_GATES.md](FEATURE_GATES.md): the kernel feature gates.
- [../development/feature-flags.md](../development/feature-flags.md): the
  developer-oriented feature flag catalogue.

For the authoritative list, read the `[features]` table in each crate's
`Cargo.toml`.
