# Roadmap

WeftOS uses workspace-level lockstep semver (ADR-001): workspace crates share one version
through `[workspace.package]` in the root `Cargo.toml`, and a breaking change bumps the
minor version while a non-breaking change bumps the patch. The current release is
**0.8.4** (2026-10-27, `CHANGELOG.md`). The workspace has 65 member crates, 40 of which are
published on crates.io (method and figures: docs refresh feature inventory, 2026-10-27).

This page used to hold a forward plan written in March 2026 (0.1 foundation, 0.2 Tauri GUI,
0.3 enterprise). Reality diverged from it: the Tauri GUI was dropped for egui, and the
version line went from 0.6.20 straight to 0.8.0. What follows is the record of what each
line actually delivered, followed by what is open. The full list of changes per release is on
[Release Notes](/docs/weftos/vision/releases).

`development-0.7.0` work stream onto the 0.6 line.

## Open at 0.8.4

Items the repo itself records as unfinished, with their source:

- Many ADRs are still Proposed: 062 to 069, 084 to 087, 106 and 113 to 120 (status lines in
  `docs/adr/`, read 2026-10-27). ADR-102 is partially implemented, and 095 to 098 are Draft.
- Several egui apps began as stubs (`crates/clawft-gui-egui/src/apps/mod.rs` header).

This page does not commit dates or scope for 0.9 or later. Planning lives on the dashboard
board, not in the docs site.

## 1.0 criteria

These are the conditions this page has carried since the Sprint 11 review. They have not been
re-assessed against 0.8.4, and none is claimed met.

- Public API stable across two or more minor releases without breaking changes
- Production users depending on API stability
- Security audit completed
- All public APIs documented
- Migration path from every 0.x version documented

## Stability notice

WeftOS is pre-1.0. The API may change between minor versions. Documentation tracks the
latest development version until 1.0, when versioned docs will be introduced.
