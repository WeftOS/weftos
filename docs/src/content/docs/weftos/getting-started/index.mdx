# What is WeftOS

WeftOS is an AI operating system written in Rust. It gives agents persistent memory, an auditable record of what they did, and governed access to tools, models and hardware, and it runs on anything from a single-board computer to a browser tab to a server.

It is built in layers:

- **clawft** is the agent runtime. It connects to LLM providers (hosted or local), handles conversations across channels, runs tools and skills, and keeps session memory. The `weft` CLI drives it.
- **The WeftOS kernel** manages processes, typed IPC, capability-based access, governance, and an append-only hash chain (ExoChain) that records privileged actions. The `weaver` CLI operates it.
- **ECC** is the cognitive layer: a causal graph with HNSW vector search that agents use as long-term memory.
- **The node daemon** ties the layers together on each machine. It hosts per-project kernels, joins machines into a mesh, runs cogs (sandboxed workloads, many of them sensor drivers), and carries cog data over the cogbus broker.

## What is in v0.8.4

- A per-user daemon with a kernel per project (`weaver project add|up|down|status|remove`, ADR-103).
- A mesh with signed membership, QUIC transport and pairing (`weaver mesh`, ADR-103, ADR-120).
- Cogs and governed workload placement (`weaver cog`, `weaver workload`, ADR-099, ADR-100), with the cog repository and Cog Host now in the separate `WeftOS/weftos-cogs` repository.
- The cogbus data-plane broker for readings, streams, blobs and mesh topics (ADR-122).
- A tailnet router that puts one HTTPS front door on a dev machine (`weaver route`, ADR-116; off by default, and the ADR's status is still Proposed).
- A chief-of-staff agent surface (`weft cos`, ADR-118, status Proposed).
- Signed releases and verified self-update (`weaver update`).
- The native GUI is egui. The Tauri shells were removed in 0.8.4-rc.15.

The [release notes](/docs/weftos/vision/releases) list every release, and each ADR is in the repository's `docs/adr/`. Pages on the 0.8.x platform features are being added to this site; until then the repository guides under `docs/guides/` are the reference.

## Architecture overview

```
+-------------------------------------------------------------------+
|  clawft: LLM providers, channels, tools, skills, agent loop       |
+-------------------------------------------------------------------+
|  WeftOS kernel: processes, IPC, governance, ExoChain, mesh, apps  |
+-------------------------------------------------------------------+
|  ECC: causal graph, cognitive tick, HNSW memory                   |
+-------------------------------------------------------------------+
|  Node daemon: projects, cogs, cogbus, placement, router           |
+-------------------------------------------------------------------+
|  Platforms: native, WASI, browser (WASM), edge, Docker            |
+-------------------------------------------------------------------+
```
