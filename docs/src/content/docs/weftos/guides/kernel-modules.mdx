# WeftOS Kernel Modules

`crates/clawft-kernel/src/` has 224 entries (files and directories) and exports 187 top-level modules at 0.8.4 (`git ls-tree` count and `grep -c '^pub mod\|^mod ' src/lib.rs`). The earlier version of this page was a per-file reference for 25 source files with line counts and public API listings. It had drifted badly (for example it described `IpcScope` variants `SameAgent` and `Named` and a `SandboxPolicy` enum that do not exist, and `Pid` as `u32` when it is `u64`), so it was replaced by this index. Per-type detail is in the pages below, each checked against the code; for anything else read the module header in the source, which is kept next to the code.

Which feature each module needs is in the table on [Kernel Architecture](/docs/weftos/architecture) and in [Feature Flags](/docs/weftos/guides/feature-flags).
