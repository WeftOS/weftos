K8 is the human interface layer of WeftOS: real-time visibility into kernel state and
interactive administration.

**Source**: `crates/clawft-gui-egui/`
**Stack**: Rust, egui/eframe (native and WASM)
**Decision**: ADR-038 (Tauri) is superseded by the egui shell (2026-04-28, WEFT-242).

## Surfaces

- **Native**: the `weft-gui-egui` binary. Build it with `scripts/build.sh gui-egui`.
- **Editor panel**: a WASM build of the same crate, hosted inside VS Code and Cursor by
  `extensions/vscode-weft-panel/`.

The shell talks to the kernel through substrate RPCs (`read`, `subscribe`, `publish`,
`notify`) rather than Tauri `invoke` commands and events.

## History

The first K8 GUI was a React 19 + Vite app in `gui/` wrapped in a Tauri 2.0 shell
(`gui/src-tauri`), with a second Tauri shell around the dashboard in `clawft-ui/src-tauri`.
Neither was released, and both were removed on 2026-10-18.
