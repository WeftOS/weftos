WeftOS ships two binaries.

- `weft` is the agent and assistant CLI: agent sessions, the gateway, the chief-of-staff host, MCP, memory, skills, tools, routing, workspaces and security audits. Reference: [weft commands](/docs/clawft/cli-reference-weft).
- `weaver` is the operator CLI for the kernel daemon and the machine mesh: kernel, projects, agents, apps, workloads, models, cogs, mesh, fleet, exposures, the cog data plane, the tailnet router, chain and custody, topology and updates. Reference: [weaver commands](/docs/clawft/cli-reference-weaver).

Both references are generated from the built binaries' `--help` by `scripts/gen-cli-reference.sh` and checked in CI, so they list every command and subcommand that exists in the release. Run `weft <command> --help` or `weaver <command> --help` for the same text locally. The same content is in Markdown at `docs/reference/cli.md`.

## Global flags

| Binary | Flag | Description |
|--------|------|-------------|
| both | `-v`, `--verbose` | Enable debug-level logging |
| both | `-h`, `--help` | Print help |
| both | `-V`, `--version` | Print version |
| `weft` | `--project <ULID>` | Use the kernel serving this project (see `weft project list`) |
| `weft` | `--runtime <DIR>` | Use the kernel whose runtime directory is `DIR` (overrides `WEFTOS_RUNTIME_DIR`) |
| `weaver` kernel commands | `-c`, `--config <CONFIG>` | Config file path (overrides auto-discovery) |
| `weaver` kernel commands | `--profile <PROFILE>` | Daemon profile; `user` addresses the per-user daemon. Falls back to `WEAVER_PROFILE` |

Flags other than these belong to individual commands; see the generated pages.
