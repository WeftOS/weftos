#### `weaver cog checkout`

```text
Check out a Cognitum cog through the mesh's Seed steward, approve its hashes, or list grants and approvals (ADR-106; needs the daemon)

Usage: weaver cog checkout [OPTIONS] [REFERENCE]
       weaver cog checkout <COMMAND>

Commands:
  approve      Approve the hashes of a checked-out cog version (operator, Admin)
  status       Grants and approvals this node holds
  release      End a checkout: the steward asks the Seed for a withdrawal, which is flooded (operator, Admin; run on the steward). The same Seed call also renews every other active checkout of the mesh
  renew        Renew now instead of at the next 12-hourly pass (Admin; run on the steward). The Seed renews every active checkout in one call
  list         Held grants, approvals and expiry (read-only)
  reset-floor  Forget the grant clock high-water mark (alias of `weaver workload node reset-floor`); changes nothing without `--confirm <floor>`

Arguments:
  [REFERENCE]  `<cog>@<version>` (`latest` is allowed) to check out

Options:
  -v, --verbose      Enable verbose (debug-level) logging
      --arch <ARCH>  Target arch (default: this node's)
      --json         Print raw JSON
  -h, --help         Print help
```

##### `weaver cog checkout approve`

```text
Approve the hashes of a checked-out cog version (operator, Admin)

Usage: weaver cog checkout approve [OPTIONS] --operator-key <OPERATOR_KEY> [REFERENCE]

Arguments:
  [REFERENCE]  `<cog>@<version>` (an exact version)

Options:
      --operator-key <OPERATOR_KEY>   Operator key file (hex seed), pinned on the daemon
  -v, --verbose                       Enable verbose (debug-level) logging
      --sha256 <SHA256>               Approve exactly this sha256 (repeat); default: every artifact of the held grant
      --reapprove-orphaned            Re-sign, for the current mesh id, every approval a `mesh_nonce` change orphaned
      --confirm <CONTENT_KEY|DIGEST>  Sign and send, pinned to what the dry run printed: the approval's content key, or with `--reapprove-orphaned` the batch digest. Without it the content is shown and nothing is signed; a value that no longer matches the freshly prepared content is refused
  -h, --help                          Print help
```

##### `weaver cog source add`

```text
Add a source

Usage: weaver cog source add [OPTIONS] --kind <KIND> <NAME>

Arguments:
  <NAME>
          Name, used as the `name:cog-id` namespace

Options:
      --kind <KIND>
          `weftos`, `cognitum` or `private`

          Possible values:
          - weftos:   WeftOS / WeaveLogic signed registry
          - cognitum: Cognitum app registry (licence required to install)
          - private:  The project's own signed registry

  -v, --verbose
          Enable verbose (debug-level) logging

      --url <URL>
          registry.json / app-registry.json URL, file path or repo directory (a `cognitum` source defaults to Cognitum's public registry)

      --key <KEYS>
          Ed25519 public key (64 hex) allowed to sign this source (repeat). Required for `private`

      --priority <PRIORITY>
          Higher wins when a bare id is in several sources

          [default: 0]

      --user
          Edit the user default list instead of the project

      --allow-insecure
          Development only: let a cognitum source use http:// or a local path

  -h, --help
          Print help (see a summary with '-h')
```
