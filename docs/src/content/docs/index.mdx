# WeftOS Documentation

WeftOS is an AI operating system written in Rust. This is documentation for v0.8.4. It is built in layers:

- **clawft** is the agent runtime. It connects to hosted and local LLMs, runs tools and skills, and handles channels such as the CLI, web, Slack and Discord.
- **The WeftOS kernel** provides processes, typed IPC, capability checks, constitutional governance, and an append-only hash chain (ExoChain) that records privileged actions.
- **ECC** is the cognitive layer: a causal graph with vector search that gives agents persistent memory.
- **The node daemon** (`weaver`) runs on each machine. It hosts a kernel per project, joins machines into a mesh, and runs cogs (sandboxed workloads, including sensor drivers) with governed placement.
